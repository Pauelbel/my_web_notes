## Что это

RAG (Retrieval-Augmented Generation) — архитектура, где LLM получает контекст из баз знаний перед генерацией ответа. Тестирование RAG включает проверку релевантности поиска, качества ответов и точности.

## Инструменты для оценки качества

- **Ragas** (Python-библиотека) — фреймворк для метрик RAG: ответная точность, релевантность, полнота
- **DeepEval** (JavaScript/TypeScript) — аналогичный инструмент с поддержкой кастомных тестов и интеграцией в CI/CD

## Список инструментов

| Инструмент | Язык | Описание |
|------------|------|----------|
| Ragas | Python | Оценка метрик качества RAG (answer_correctness, semantic_similarity) |
| DeepEval | JavaScript | Тестирование LLM-ответов с поддержкой автоматических тестов в сборках |

## Как тестировать

1. Запустить Ragas/DeepEval на наборе промптов и ожидаемых ответов
2. Проверить метрики: точность, релевантность, полноту контекста
3. Сравнить результаты между версиями системы
