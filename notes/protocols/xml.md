## Что это

Язык разметки для обмена структурированными данными: дерево элементов с атрибутами, строгий синтаксис, структура описывается схемой (XSD, реже DTD). Через пространства имён (`xmlns`) в одном документе смешиваются словари из разных схем.

Где применяется: SOAP и старые enterprise-API, банковские и государственные интеграции (ISO 20022, ЭДО, ФНС), конфиги (Maven `pom.xml`, Android, Spring), RSS/Atom, SVG, офисные форматы (`.docx`, `.xlsx`).

## Как тестировать

Чем: `xmllint` (`--noout --schema` для проверки по XSD), XPath для проверок значений, SoapUI или Postman для SOAP, pytest + `lxml`.

### Синтаксис
- [ ] невалидный XML (незакрытый тег, лишний `&`, два корня) отклоняется понятной ошибкой, а не 500
- [ ] спецсимволы `< > & " '` в данных экранируются и возвращаются как были
- [ ] кириллица и эмодзи не ломаются, кодировка в `<?xml encoding?>` совпадает с реальной
- [ ] данные внутри `CDATA` обрабатываются так же, как обычный текст
- [ ] BOM в начале файла не ломает разбор

### Схема (XSD)
- [ ] ответ сервиса проходит валидацию по актуальной XSD
- [ ] запрос без обязательного элемента отклоняется
- [ ] неверный тип (`abc` в `xs:int`, дата не в ISO 8601) отклоняется
- [ ] границы: `minOccurs`/`maxOccurs`, длина строк, `enumeration`
- [ ] неизвестный элемент: поведение соответствует договорённости (отклонить или проигнорировать)

### Структура и пространства имён
- [ ] другой префикс с тем же `xmlns` URI принимается
- [ ] элемент без нужного пространства имён не принимается за «свой»
- [ ] порядок элементов при `xs:sequence` проверяется, при `xs:all` — нет
- [ ] пустой элемент (`<a/>`), пустая строка (`<a></a>`) и отсутствие элемента различаются там, где это важно
- [ ] `xsi:nil="true"` обрабатывается как null

### Безопасность
- [ ] XXE: внешние сущности (`<!ENTITY x SYSTEM "file:///etc/passwd">`) не раскрываются
- [ ] «billion laughs» (вложенные сущности) не вешает сервис
- [ ] очень большой документ и глубокая вложенность упираются в лимит, а не в OOM
- [ ] в сообщениях об ошибках нет стектрейсов и путей сервера

### Совместимость
- [ ] новое необязательное поле в ответе не ломает старых клиентов
- [ ] пробелы и переносы строк между тегами не влияют на результат
- [ ] числа и даты не зависят от локали сервера (`1.5`, а не `1,5`)
