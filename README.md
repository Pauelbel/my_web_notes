# qa-notes

Технология → зачем → как бы я её тестировал. Графитовая тема: сворачиваемое меню, граф связей на главной, заметки с нумерованными разделами и чек-листами.

## Запуск

```bash
pip install markdown
python build.py                       # собирает notes/ → site/
python -m http.server -d site 8000    # смотреть на http://localhost:8000
```

## Структура

```
notes/<воркспейс>/<slug>.md   заметки (папка = воркспейс в меню)
notes/_about.md               страница «Обо мне»
templates/base.html           каркас страницы
templates/style.css           тема (цвета в :root, светлая тема ниже)
templates/graph.js            граф на главной
build.py                      сборка (имя, аватар, ссылка на GitHub — в начале файла)
site/                         готовый сайт (не коммитить, собирает CI)
```

## Формат заметки

```markdown
---
title: Redis
status: done        # done / draft / todo
summary: одна строка для списка и описания страницы
updated: 2026-10-24
---

## Что это            ← коротко: что за технология и где применяется

## Как тестировать     ← карточка-чек-лист с прогрессом
### Группа
- [ ] пункт

## Ссылки              ← документация и статьи

## См. также           ← в тексте не выводится, из ссылок строится строка «Связано»
[[postgresql]]
```

`[[slug]]` — ссылка на заметку по имени файла. Связи из них рисуют граф и строку «Связано» под заголовком (в обе стороны). Ссылка на ещё не написанную заметку подсвечивается красным.

## Публикация на GitHub Pages

Settings → Pages → Source: GitHub Actions. При пуше в `main` workflow из `.github/workflows/pages.yml` соберёт и опубликует сайт.
