# Вики заметок

Пользователь даёт текст и говорит, что с ним сделать. Делай то, что он сказал, — формат и заголовки тоже его.

## Перед работой

Прочитай `INDEX.md` (в корне, рядом с `build.py`) — каталог всех заметок.
- Есть подходящая заметка — скажи пользователю, какая, и спроси: дополнить её или создать новую.
- Новая заметка, а раздел не назван — предложи раздел из `INDEX.md` (или новый) и спроси пользователя.

## Заметка

- Файл `notes/<раздел>/<имя>.md`, имена латиницей через дефис. Новый раздел — папка и `_section.md`
  с русским названием: `---` / `title: Базы данных` / `---`.
- Начало файла:
  ```
  ---
  title: Название по-русски
  status: draft
  summary: одна строка — о чём заметка
  updated: <сегодня>
  ---
  ```
- Текст пользователя причеши: опечатки, абзацы, списки, таблицы. От себя — только если без этого непонятно.
- Формат не задан — «## Что это» и 1–3 своих раздела по смыслу, по-русски. Без HTML.
  «## Как тестировать» (чек-лист `- [ ]`) — только если попросили.
- Связи: в конце `## См. также` и `[[имя]]` заметок из `INDEX.md`, которые правда по теме.
  Обратную ссылку сайт ставит сам — другие заметки ради связей не правь.
- `about.md` и `site/` не трогай.

## После правок

Всегда собери: `run` с командой `.venv/bin/python build.py` (Windows: `.venv\Scripts\python build.py`).
Есть строки `предупреждение:` — исправь и собери снова.
«Опубликуй» — `git_commit`, потом `run` с `git push`.
